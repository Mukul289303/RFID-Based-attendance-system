# RFID Attendance System Documentation

## Project Overview

The RFID Attendance System is an IoT-based attendance solution developed using the ESP32 microcontroller and the MFRC522 RFID Reader. The system automatically records attendance by scanning RFID cards or tags and uploads the attendance data to Google Sheets over Wi-Fi.

---

# Objectives

- Automate attendance recording
- Reduce manual errors
- Store attendance records in the cloud
- Provide real-time date and time logging
- Improve attendance management efficiency

# Working Principle

1. Power on the ESP32.
2. Connect to the configured Wi-Fi network.
3. Scan an RFID card or tag.
4. Read the UID using the MFRC522 module.
5. Verify the UID.
6. Fetch the current date and time.
7. Upload the attendance record to Google Sheets.
8. Display attendance status.
